# โรงงานผลิตชีท TPAT3 — คู่มือติดตั้ง

เขียนสำหรับคนที่ไม่เคยทำเรื่องนี้มาก่อน ทำตามทีละข้อได้เลย

---

## สิ่งที่ต้องลงก่อน (ทำครั้งเดียว)

### 1. ฟอนต์ Sarabun
เปิดโฟลเดอร์ `fonts` → คลิกขวาที่ `Sarabun-Regular.ttf` → **Install**
ทำแบบเดียวกันกับ `Sarabun-Bold.ttf`
(ไม่ลงฟอนต์ ตัวหนังสือในชีทจะเพี้ยน)

### 2. Python
โหลดจาก https://www.python.org/downloads/
**ตอนติดตั้งต้องติ๊ก "Add Python to PATH"** ไม่งั้นจะเรียกไม่เจอ

### 3. Node.js
โหลดตัว LTS จาก https://nodejs.org/ กด Next รัวๆ ได้เลย

### 4. LibreOffice (ไม่บังคับ)
https://www.libreoffice.org/ — ใช้แปลง .docx เป็น PDF อัตโนมัติ
ถ้าไม่ลง ก็เปิด .docx ใน Word แล้ว Save as PDF เอง ได้เหมือนกัน

### 5. Claude Code
เปิด **PowerShell** แล้วพิมพ์:
```powershell
npm install -g @anthropic-ai/claude-code
```

## เตรียมโปรเจกต์ (ทำครั้งเดียว)

เปิด PowerShell แล้ว `cd` เข้ามาที่โฟลเดอร์นี้ จากนั้น:

```powershell
npm install
pip install pillow numpy
```

ลองรันดูว่าใช้ได้ไหม:
```powershell
python gen.py
```
ถ้าขึ้นบรรทัดสรุปจำนวนข้อ = ผ่าน

## ใช้งานประจำวัน — ออกชีท

```powershell
make.bat easy 50 1     REM  ★☆☆  50 ข้อ  ชุดที่ 1
make.bat std  50 2     REM  ★★☆
make.bat hard 50 3     REM  ★★★
```

ไฟล์ออกมาที่โฟลเดอร์ `out\`

หรือสั่งเองทีละขั้น:
```powershell
python gen.py
node build.js --mix hard --n 40 --set 5 --out out\ชุด5.docx
```

## ใช้งาน Claude Code — ให้ agent ช่วยทำงาน

พิมพ์ `claude` ใน PowerShell ตอนที่อยู่ในโฟลเดอร์นี้ แล้วคุยกับมันเป็นภาษาไทยได้เลย

มันจะอ่าน `CLAUDE.md` เองอัตโนมัติ เลยรู้กติกาทั้งหมดของโปรเจกต์ ไม่ต้องอธิบายใหม่ทุกครั้ง

**ทีมงานที่มีอยู่แล้ว** (อยู่ใน `.claude\agents\`)

| ชื่อ | หน้าที่ |
|---|---|
| `item-writer` | เขียนโจทย์ใหม่ตามแนวและระดับดาวที่สั่ง |
| `verifier` | นักเรียนจำลอง ลองแก้โจทย์โดยไม่เห็นเฉลย ใช้จับโจทย์กำกวม |
| `calibrator` | ให้ดาว 1-3 โดยเทียบกับข้อสอบจริง |
| `thai-editor` | ขัดสำนวนไทยให้เหมือนข้อสอบจริง |
| `renderer-builder` | เขียนเครื่องวาดรูปตัวใหม่เมื่อโจทย์แนวใหม่ต้องใช้ |

**ตัวอย่างคำสั่ง**

```
ใช้ item-writer เขียนโจทย์อนุกรมกฎซ่อนสองชั้น ระดับ 3 ดาว มา 10 ข้อ
เสร็จแล้วให้ verifier 3 ตัวลองแก้ ถ้าตอบไม่ตรงกันให้ตีกลับไปแก้
```

```
เอาโจทย์พาร์ทที่ 1 ทั้งหมดในคลัง ส่งให้ calibrator ให้ดาวใหม่
โดยเทียบกับ reference/ แล้วสรุปมาว่าข้อไหนต้องเลื่อนระดับ
```

```
คลังตอนนี้ไม่มีโจทย์แนว "ซ้อนแผ่นบังแสง" เลย
ให้ renderer-builder เขียนเครื่องวาดก่อน แล้วให้ item-writer ออกโจทย์ 8 ข้อ
```

**เคล็ดลับ**
- สั่งทีละก้อน อย่าสั่งยาวเป็นหน้า มันจะหลง
- ทุกครั้งที่มันบอกว่าเสร็จ ให้สั่ง `รัน python gen.py แล้วออกชีทมาดู` เพื่อเช็คของจริง
- ถ้าไม่ชอบผลลัพธ์ บอกตรงๆ ว่าไม่ชอบตรงไหน มันแก้ให้ได้

## ไฟล์ในโปรเจกต์

| ไฟล์ | คืออะไร |
|---|---|
| `CLAUDE.md` | กติกาของโปรเจกต์ — Claude Code อ่านเองทุกครั้ง แก้ไฟล์นี้ = เปลี่ยนกติกา |
| `gen.py` | คลังโจทย์ระดับ 1-2 + ตัวประกอบคลังทั้งหมด |
| `hard.py` | คลังโจทย์ระดับ 3 |
| `draw.py` | เครื่องวาดรูปทุกชนิด (ลูกบาศก์ ตาราง รูปคลี่ ดาว หัวกระดาษ) |
| `cube.py` | กลไกพับรูปคลี่และหมุนทรง 24 มุม — ใช้ตรวจว่าคำตอบถูกข้อเดียวจริง |
| `build.js` | ตัวประกอบชีท อ่านคลังแล้วพ่น .docx |
| `questions.json` | คลังโจทย์ที่สร้างเสร็จแล้ว (สร้างใหม่ทุกครั้งที่รัน gen.py) |
| `reference/` | ข้อสอบจริงไว้ศึกษาแนว — **ห้ามลอก ดูได้แค่แนว** |
| `img/` | รูปที่ถูกวาดออกมา (สร้างใหม่อัตโนมัติ ลบทิ้งได้) |
| `out/` | ชีทที่ออกมาแล้ว |
