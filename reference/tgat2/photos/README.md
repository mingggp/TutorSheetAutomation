# รูปถ่ายโจทย์จากติวเตอร์

วางไฟล์รูปไว้ในโฟลเดอร์นี้ได้เลย **ไม่ต้องตั้งชื่อให้สวย** ชื่อจากกล้องก็ใช้ได้

```
reference/tpat3/photos/     ← TPAT3
reference/tgat2/photos/     ← TGAT2
```

รองรับทั้ง `.jpg` จากแอนดรอยด์และ `.heic` จากไอโฟน ถ่ายเอียงหรือมีเงาก็อ่านออก

## ไฟล์พวกนี้ไม่ขึ้น GitHub

`.gitignore` กันไว้แล้วเหมือนกับ PDF อ้างอิง เพราะเป็นลิขสิทธิ์ของผู้อื่น (กติกาข้อ 3)
**สิ่งที่ขึ้น GitHub คือ `DIGEST-*.md` ซึ่งเป็นงานเขียนของเราเอง** ไม่ใช่ตัวโจทย์

ย้ายเครื่องเมื่อไหร่ต้องเอารูปมาวางเอง เหมือน PDF

## สิ่งที่มีค่าที่สุดคือลายมือที่ทดไว้ ไม่ใช่ตัวโจทย์

ตัวโจทย์บอกได้แค่ว่า *ถามอะไร* แต่ลายมือที่ทดบอกว่า **ต้องคิดกี่ชั้น และติดตรงไหน**
ซึ่งเป็นสิ่งที่เดาจากตัวโจทย์เปล่า ๆ ไม่ได้ และเป็นตัวตัดสินว่าข้อนั้นควรเป็นกี่ดาว

ถ้าถ่ายมาพร้อมรอยขีดฆ่าหรือทางที่ลองแล้วไม่เวิร์ก **ยิ่งดี** เพราะมันบอกกับดักของข้อนั้น
ซึ่งเอาไปใช้ออกแบบตัวลวงได้ตรงกว่าการเดาเอง

## บอกเพิ่มได้ถ้าสะดวก (ไม่บังคับ)

พิมพ์สั้น ๆ ในแชทตอนส่งก็พอ ไม่ต้องเขียนลงไฟล์

- ข้อนี้มาจากพาร์ทไหน (ตัวเลข · มิติสัมพันธ์ · เชิงกล · เชิงวิทย์)
- คิดว่ากี่ดาว หรือเด็กส่วนใหญ่ทำไม่ได้ไหม
- ถ้าเป็นข้อที่ *อยากได้แนวนี้แต่ยังไม่มีในคลัง* บอกไว้จะได้ทำก่อน

## จะเอาไปทำอะไรต่อ

1. อ่านรูป แล้วถอดเป็น *แนว* ลง `DIGEST-*.md` — **ไม่คัดลอกตัวเลขหรือถ้อยคำ** (กติกาข้อ 3)
2. ถ้าแนวนั้นยังไม่มีในคลัง เขียนเครื่องผลิตใหม่พร้อมตัวตรวจคำตอบ
3. ถ้ามีแล้วแต่ของเราง่ายกว่า ใช้ลายมือที่ทดเป็นตัวเทียบว่าต้องเพิ่มชั้นตรงไหน
