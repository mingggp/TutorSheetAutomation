## วิธีอ่านไฟล์พวกนี้

**`pdftotext` อ่านภาษาไทยไม่ออก** ตัวอักษรไทยหายหมด เหลือแต่ตัวเลข และบางไฟล์เป็นสแกนล้วนไม่มี text layer เลย
เครื่องนี้ไม่มี `pdftoppm` ด้วย ทำให้ Read tool เปิด PDF ตรง ๆ ไม่ได้ → **ต้องเรนเดอร์เป็น PNG ด้วย PyMuPDF ก่อน**

```python
import pymupdf
d = pymupdf.open("reference/tgat2/TGAT2 Dek66.pdf")
d[7].get_pixmap(dpi=125).save("out.png")     # index เริ่มที่ 0 → หน้าที่ 8
```

text layer ใช้ได้อย่างเดียวคือหาว่าเลขข้อไหนอยู่หน้าไหน (ตัวเลขไม่หาย)

**อ่าน `DIGEST-*.md` ก่อนเสมอ** ถ้าแนวที่ต้องการถูกถอดไว้แล้ว จะได้ไม่ต้องเปิด PDF ซ้ำ
