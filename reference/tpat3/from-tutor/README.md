# ไฟล์โจทย์เพิ่มเติมจากติวเตอร์

วางไฟล์ไว้ในโฟลเดอร์นี้ได้เลย **ไม่ต้องตั้งชื่อให้สวย** ชื่อจากเครื่องก็ใช้ได้

```
reference/tpat3/from-tutor/     ← TPAT3
reference/tgat2/from-tutor/     ← TGAT2
```

**รับได้ทุกแบบ** — PDF จากโหมดเอกสาร · รูป `.jpg` จากแอนดรอยด์ · `.heic` จากไอโฟน
สแกนเอียงหรือมีเงาก็อ่านออก ถ้าเป็น PDF หลายหน้ารวมกันยิ่งดี เพราะเปิดอ่านทีเดียวจบ

## ไฟล์พวกนี้ไม่ขึ้น GitHub

`.gitignore` กันไว้แล้วทั้ง PDF และไฟล์รูป เพราะเป็นลิขสิทธิ์ของผู้อื่น (กติกาข้อ 3)
**สิ่งที่ขึ้น GitHub คือ `DIGEST-*.md` ซึ่งเป็นงานเขียนของเราเอง** ไม่ใช่ตัวโจทย์

ย้ายเครื่องเมื่อไหร่ต้องเอาไฟล์มาวางเอง เหมือน PDF อ้างอิงตัวอื่น

## สิ่งที่มีค่าที่สุดคือลายมือที่ทดไว้ ไม่ใช่ตัวโจทย์

ตัวโจทย์บอกได้แค่ว่า *ถามอะไร* แต่ลายมือที่ทดบอกว่า **ต้องคิดกี่ชั้น และติดตรงไหน**
ซึ่งเดาจากตัวโจทย์เปล่า ๆ ไม่ได้ และเป็นตัวตัดสินว่าข้อนั้นควรเป็นกี่ดาว

ถ้ามีรอยขีดฆ่าหรือทางที่ลองแล้วไม่เวิร์กติดมาด้วย **ยิ่งดี** เพราะนั่นคือกับดักของข้อนั้น
ซึ่งเอาไปออกแบบตัวลวงได้ตรงกว่าการเดาเอง

## บอกเพิ่มได้ถ้าสะดวก (ไม่บังคับ)

พิมพ์สั้น ๆ ในแชทตอนส่งก็พอ ไม่ต้องเขียนลงไฟล์

- มาจากพาร์ทไหน (ตัวเลข · มิติสัมพันธ์ · เชิงกล · เชิงวิทย์)
- คิดว่ากี่ดาว หรือเด็กส่วนใหญ่ทำไม่ได้ไหม
- ถ้าเป็นข้อที่ *อยากได้แนวนี้แต่ยังไม่มีในคลัง* บอกไว้จะได้ทำก่อน

## จะเอาไปทำอะไรต่อ

1. อ่านไฟล์ แล้วถอดเป็น *แนว* ลง `DIGEST-*.md` — **ไม่คัดลอกตัวเลขหรือถ้อยคำ** (กติกาข้อ 3)
2. ถ้าแนวนั้นยังไม่มีในคลัง เขียนเครื่องผลิตใหม่พร้อมตัวตรวจคำตอบ
3. ถ้ามีแล้วแต่ของเราง่ายกว่า ใช้ลายมือที่ทดเป็นตัวเทียบว่าต้องเพิ่มชั้นตรงไหน
