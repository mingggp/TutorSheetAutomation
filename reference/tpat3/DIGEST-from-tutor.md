## 1. สิ่งที่ลายมือบอก และเราเดาเองไม่ได้

**ข้ออนุมานตัวดำเนินการ ติวเตอร์ลองผิดสองรอบก่อนเจอกฎ**
เห็นรอยขีดฆ่ากฎที่ลองแล้วไม่ผ่าน แล้วเขียนกฎที่ถูกทับลงไป
→ ยืนยันว่า **กับดักของแนวนี้คือกฎหลายตัวที่อธิบายตัวอย่างแรก ๆ ได้เหมือนกัน**
ตัวตรวจใน `numeric.inferop` ที่ตัดกฎคู่แข่งทิ้งอยู่แล้ว **มาถูกทางแล้ว** ให้คงไว้

**มีข้อที่ต้นฉบับกำกวมจริง** — ข้อหนึ่งติวเตอร์วงคำตอบไว้สองข้อแล้วเขียนว่า "ดูคู่"
→ แนวนี้ออกพลาดง่ายมาก ของเราต้องพิสูจน์ความเป็นเอกลักษณ์ของกฎทุกครั้ง ห้ามยกเว้น

**กฎที่เจอในของจริงซึ่งตาราง `OPS` ของเรายังไม่มี**
`b(a+b)+a` · `(a×b)+คงที่ที่ลดลงเป็นลำดับ` · ตัวดำเนินการที่ผลลัพธ์เดินเป็นอนุกรมอีกชั้น

## 2. แนวใหม่ของพาร์ทที่ 1 (ตัวเลข)

### 2.1 ที่ผลิตด้วยโค้ดได้ทันที

| แนว | กลไก | สถานะ |
|---|---|---|
| **อนุกรมกลับหลักตัวเลข** | พจน์จริงเป็นกำลังสอง/กำลังสาม แต่พิมพ์กลับหลัก ต้องกลับก่อนถึงเห็นกฎ | **ทำแล้ว** |
| **สัญลักษณ์รูปแทนตัวเลข** | ตารางสัญลักษณ์ มีผลรวมกำกับแต่ละแถว หาค่าแถวที่ขาด | **ทำแล้ว** |
| **ตารางเติมเลขให้ผลรวมตรง** | ใส่ 1-9 ห้ามซ้ำ ให้ทุกแถวและหลักรวมได้ตามหัวตาราง | **ทำแล้ว** |
| **อนุกรมอักษรไทยผสมอังกฤษ** | อักษรไทยเดินทางหนึ่ง อักษรอังกฤษเดินถอยหลังอีกทาง | **ทำแล้ว** |
| **ตรรกะจริง-เท็จแบบกำหนดจำนวน** | บอกว่ามีคนพูดจริงกี่คน ทำให้ไล่กรณีได้แคบลงแต่ต้องคุมให้ครบ | **ทำแล้ว** |
| อนุกรมแฟกทอเรียลซ้อน | สองเส้นสลับ เส้นหนึ่งเป็นแฟกทอเรียล อีกเส้นเป็นผลคูณไล่ | ยังไม่ทำ |
| ตรรกะแบ่งกลุ่มด้วยเงื่อนไขถ้า-แล้ว | แบ่งคนเป็นสองกลุ่ม เงื่อนไขเป็นประโยคเงื่อนไข | ยังไม่ทำ |
| ผังกล่องตัวเลขเชื่อมเป็นเส้นทาง | กล่องเลขสามหลักต่อกันเป็นงู กฎอยู่ที่การสลับหลัก | ยังไม่ทำ |
| รากซ้อนสลับเครื่องหมาย | ต่างจากรากซ้อนธรรมดา ต้องยกกำลังสองสองรอบ | ยังไม่ทำ |

### 2.2 ที่ต้องเขียนมือ

- **ตรรกะจัดที่นั่งสองฝั่ง** — ห้องซ้าย 4 ห้องขวา 2 มีห้องปิดท้าย เงื่อนไขยาวครึ่งหน้า
- **ตรรกะนิทานยาว** — ภูติหกตนพูดถึงกันเอง ซ้อนกับการหาว่ากล่องใบไหนมีสมบัติ
- **ตรรกะเรียงอันดับจากผลต่างเวลา** — "คู่ที่ห่างกันน้อยที่สุดคือ C กับ A"

> ทั้งสามแบบเป็น *โจทย์ยาวที่ต้องแกะ* ซึ่งเป็นจุดแข็งของ TPAT3 จริง
> เครื่องผลิตทำโครงได้แต่ภาษาต้องเขียนมือ ไม่งั้นอ่านไม่รู้เรื่อง

### 2.3 แนวที่ digest เดิมระบุไว้ว่าออกจริง แต่เรายังไม่เคยทำ

- **อ่านกราฟแท่ง** หาค่าเฉลี่ยถ่วงน้ำหนัก (เจอในชุดที่ 1)
- **อสมการที่ตัวเลือกเป็นกราฟเส้นจำนวน** — ตัวเลือกเป็นรูป ไม่ใช่ตัวเลข
- **สมการฟังก์ชัน** เช่น f(x+2) = ผลบวก 1 ถึง x แล้วถาม f(f(5))

## 3. แนวใหม่ของพาร์ทที่ 2 (มิติสัมพันธ์)

| แนว | กลไก | สถานะ |
|---|---|---|
| **อนุกรมรูปที่ช่องหายอยู่กลาง** | ไม่ได้ถามภาพถัดไป แต่ถามภาพที่หายกลางลำดับ ยากกว่าเพราะต่อจากสองทาง | **ทำแล้ว** |
| **ตัวดำเนินการสัญลักษณ์รูป** | นิยามตัวดำเนินการ 3-4 ตัวที่กระทำกับ *ลำดับของรูป* แล้วถามนิพจน์ซ้อนวงเล็บ | ยังไม่ทำ · **ของจริง 8%** |
| **กฎการแปลงรูป แถว 1 สอนกฎ แถว 2 ใช้** | แถวแรกโชว์ ก่อน-หลัง แถวสองให้ ก่อน แล้วถาม หลัง | ยังไม่ทำ · ของจริง 3% |
| **เมทริกซ์รูปซ้อนรูป** | รูปนอก + รูปใน + การระบาย เดินเป็นละตินสแควร์สามคุณลักษณะ | ยังไม่ทำ |
| **เมทริกซ์วงซ้อน** | คุณลักษณะคือ *จำนวนวงที่ซ้อนกัน* ไม่ใช่รูปทรง | ยังไม่ทำ |
| **รูปคลี่ของทรงหลายก้อน** | ไม่ใช่ลูกบาศก์เดี่ยว แต่เป็นพอลิโอมิโนที่พับเป็นทรงสามก้อน มีหน้าแรเงาครึ่ง | ยังไม่ทำ |
| **ภาพฉายที่มีผิวเอียง** | ทรงมีหน้าลาดเอียง ไม่ใช่บล็อกตั้งฉากล้วน | ยังไม่ทำ |
| ซ้อนแผ่นบังแสงแบบกลับสี | พื้นดำเจาะรูขาว ถามแสงที่ลอดผ่าน = ต้องโปร่งทั้งคู่ | มีแล้ว (ตรรกะเดียวกัน) |
| พับกล่องที่ตัวอักษรมีทิศ | ตัวอักษรบนหน้าลูกบาศก์วางเอียงตามการพับจริง | **มีแล้ว** ยืนยันว่าทำถูกทาง |

## 4. ข้อสรุปเชิงออกแบบ

**1. ของจริงชอบให้ "กลับมุมมองก่อน" มากกว่าให้คำนวณยาก**
กลับหลักตัวเลข · ถามช่องกลางแทนช่องท้าย · ถามว่าข้อใด *ไม่* ได้ · ให้กฎมาแล้วใช้ซ้อนกัน
→ ยกระดับความยากด้วยการเปลี่ยน *มุมที่ถาม* ได้ผลกว่าการเพิ่มขนาดตัวเลข

**2. ตัวเลือกที่เป็นรูปมีเยอะกว่าที่เราทำ** แม้แต่ในพาร์ทตัวเลข (กราฟเส้นจำนวน)

**3. ข้อที่ยาวครึ่งหน้ามีจริงและมีหลายข้อ** ชีทเราสั้นกว่าของจริงมาก
ควรมีข้อยาวที่ต้องแกะเงื่อนไขอย่างน้อยชีทละ 2-3 ข้อ
